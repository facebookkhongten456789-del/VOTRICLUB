Gửi yêu cầu lấy toàn bộ danh sách dịch vụ SMM hiện có từ tài khoản đại lý API Bytemart.

Tra cứu chi tiết trạng thái của 1 đơn hàng cụ thể từ API.

Tra cứu trạng thái của nhiều đơn hàng cùng lúc từ API (cách nhau bởi dấu phẩy).

Gửi yêu cầu hủy đơn hàng loạt trên API gốc SMM.

Gửi yêu cầu kiểm tra số dư hiện tại trên tài khoản đại lý API của hệ thống Gateway/Bytemart SMM.

Yêu cầu bảo hành (refill) cho đơn hàng. Sau khi yêu cầu thành công, trạng thái sẽ tự động đổi thành Refilling.

Yêu cầu bảo hành hàng loạt (Refill) cho danh sách nhiều đơn hàng cách nhau bởi dấu phẩy.
