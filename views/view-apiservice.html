API Service Reference

Tài liệu tích hợp hệ thống kiểm tra Fanpage

Endpoint: /api/check-page

POST /api/check-page

Endpoint này sử dụng Access Token (User hoặc Page) để quét toàn bộ thông tin Fanpage từ Graph API (bao gồm trạng thái, follow, số bài đăng và các vi phạm).

Request Body (JSON)

{
  "accessToken": "EAA...", // Bắt buộc: User Token hoặc Page Token
  "pageId": "109xxxxxxxxxx", // ID của Fanpage (tuỳ chọn nếu có url)
  "url": "https://facebook.com/..." // URL Fanpage (tuỳ chọn nếu có pageId)
}

Secure Response Report

API trả về dữ liệu cơ bản. Lưu ý: Để đảm bảo tính bảo mật (ẩn các thông số quét ngầm), Object report chi tiết đã bị loại bỏ hoàn toàn khỏi response công khai.
